# How do I view analytics for several project members at once?

On the project **Members** tab, select the members with the row checkboxes, open **Bulk Actions**,
and click **View analytics**. The Analytics page opens for the project and the selected members,
and service accounts can be mixed with regular users. For a single member, use **View analytics**
in the row's **⋮** menu.

The action requires the Enterprise package and project management rights, and is available for
at most 100 selected members. Use the **Account type** filter to narrow the selection if needed.
